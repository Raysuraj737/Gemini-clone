# Gemini Clone

A responsive AI-powered chatbot web application inspired by Google Gemini, built using **React.js, Vite, and the Google Gemini API**. The application allows users to interact with an AI assistant, send prompts, and receive intelligent, dynamically generated responses.

### Key Features

* 🤖 AI-powered conversations using **Gemini 2.5 Flash**
* 🔍 **Google Search integration** for accessing up-to-date information
* 💬 Interactive chatbot interface
* ⚡ Fast and responsive frontend using **React.js + Vite**
* 🔐 Secure API key management using environment variables
* 🎛️ Configurable AI generation parameters such as temperature, Top-P, and maximum output tokens
* 📱 Responsive user interface for different screen sizes
* ⚠️ Error handling for failed API requests

### Technologies Used

* **React.js**
* **Vite**
* **JavaScript**
* **Google Gemini API**
* **@google/genai**
* **HTML5 & CSS3**

### AI Configuration

The application uses the **Gemini 2.5 Flash** model with configurable generation settings and Google Search as an additional tool to enhance responses with current information.

### Purpose

This project was developed to gain practical experience with **Generative AI, API integration, React.js, asynchronous JavaScript, environment variables, and modern frontend development**.
